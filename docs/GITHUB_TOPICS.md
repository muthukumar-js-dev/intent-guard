# GitHub Topics for Intent-Guard

To improve discoverability, please add the following topics to your GitHub repository settings.

1. Go to your repository page on GitHub.
2. Click the specific "gear" icon next to "About" in the right sidebar (or go to Settings).
3. Add the following topics:


These topics match the keywords in `package.json` where possible and target high-intent search terms.
